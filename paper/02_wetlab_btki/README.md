# 02 — Wet-lab validation of BTKi combinations

PAIRWISE ranked BTK-inhibitor combinations in DLBCL; the top of that ranking was
screened experimentally. This folder holds the screening design and the readout, so the
predicted ranking can be compared against the measured response.

## Contents

| File | Content |
|---|---|
| `data/combo_manifest_300.csv` | The 300 combinations submitted for screening |
| `data/cell_line_to_ccle.csv` | Screened cell lines mapped to CCLE/DepMap identifiers |
| `data/drug_name_to_pubchem.csv` | Drug names mapped to PubChem CIDs |
| `data/grover_batch_smiles.csv` | SMILES for the screened compounds |
| `data/grover_batch.csv` | GROVER embeddings for those compounds |
| `data/26051_0_data_set_310291_t8dn1h.xlsx` | Experimental readout as returned by the facility |
